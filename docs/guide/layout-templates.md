# Excel 出力模板

模板保存完整的编辑数据、生成设定及出力列表。**一个模板保存一个独立的 `.xlsx` 文件**，例如 `正常数据.xlsx`、`空值测试.xlsx`。不要选择原账票定义 Excel 作为模板保存目标。

## 保存和读取

1. 读取账票定义 Excel，编辑 FORM 项目，添加出力列表，设定文件名和 CSV 值。
2. 点击「名前を付けて保存...」，选择文件名和位置。文件名就是模板名称。
3. 以后点击「テンプレートを開く...」，选择文件后直接读取，确认替换当前画面和出力列表即可，无需再选择模板名。
4. 「保存」更新当前文件；「名前を付けて保存...」保存另一份独立模板；在 Excel 修改后用「再読込」刷新。

保存前请关闭 Excel。图片存放在同目录的 `<模板文件名>_assets` 文件夹。另存文件时会复制所需图片，原模板保持不变。复制或移动模板时，应把 Excel 和这个文件夹一起带走。失败保存也可能留下未引用图片。

旧的多模板 Excel 仍可打开：选择文件后，按提示输入其中一个模板的编号，再用「名前を付けて保存...」存为独立文件。程序禁止覆盖旧多模板文件，以免丢失其他模板。新版不再提供向同一文件追加模板或删除其中模板的按钮；不需要的独立文件可在文件管理器中管理。

## 从文件夹选择多个模板

点击「フォルダから選択...」读取文件夹中的 `.xlsx` 模板（不递归读取子目录，跳过 Excel 临时文件）。不符合模板格式的 Excel 会列出原因。旧多模板文件中的每个模板也会独立列出。

- 单选后点击「1件を編集」或双击：载入当前编辑窗口。
- Ctrl/Shift 多选，或点击「全選択」：使用「選択TXT一括出力」或「選択CSV一括出力」批量输出。
- 一次批量输出建立一个新的 `templates_日期时间_随机后缀` 文件夹，每份模板放在独立编号子目录中，采用该模板保存的文件名、编码、CSV 设定及出力勾选值。
- TXT 模式使用出力列表打包；没有出力列表时使用模板的编辑项目直接输出。CSV 模式需要模板保存了出力列表。

多选用于独立批量输出，不会把不同模板的设定混合进一个编辑窗口。批量读取的是文件中已保存的数据；编辑画面中的修改需要先保存。任何模板失败时，整批结果不发布，并显示失败的文件与原因；既有输出不覆盖。

## 手动编辑 Sheet

| Sheet | 用途 |
|---|---|
| テンプレート設定 | 每个设置一行；编辑「値」，不改「設定キー」和「型」。bool 用 0/1。包括 TXT/TAR 文件名规则、CSV 名、编码、列设置等。 |
| 編集項目 | 每个 FORM 项目一行，供下方 FORM 编辑区和直接输出使用。「出力」0/1 控制选中状态。 |
| 出力帳票 | 每张正面图片一行；包含图片相对路径、基础名、背面值和 CSV 各位置。位置3来自图片基础名，位置5独立于 TXT 的 FORM_ID。 |
| 出力OCR | 出力列表中的 TXT 内容，每个字段一行。通过图片ID、帐票顺、项目顺关联；同一图片可以包含多个相同或不同 FORM_ID 的帐票。 |

编辑项目区与已加入出力列表的 TXT 是独立快照。要修改列表输出的 OCR，编辑「出力OCR」，再读取模板。要修改直接输出的 OCR，编辑「編集項目」。修改 OCR 不会自动重绘已经保存的图片；如需更新图片，从编辑区重新加入出力列表。

所有数据单元格按文本保存，保留前导零、空白、换行与引号。空单元格表示明确为空，不回退到原 Excel 默认值；OCR 为空时属性和坐标也清空。Excel 公式不执行，读取时会报错；以 `=` 开头的文字请按文本输入。

坐标格式为 `X,Y,宽度,高度`。例如 `70,10,50,50` 表示从 (70,10) 开始的 50×50 方块。自动坐标固定宽高为50，每行10个、间隔10。已保存的坐标按原值读取；旧版自动坐标若已保存到默认值或模板，需要手动将后两位改为 `50,50`。

「帳票順」「項目順」从1连续编号。无字段的帐票使用项目顺0占位。不要修改表头；重复标识、缺失图片及关联错误会阻止加载。模板读取成功前不会替换画面数据。

模板可以脱离原账票定义进行直接输出及出力列表打包。点击「Excel定義を読込」会重新读取原定义并结束模板编辑模式。原有「既定値保存」仍写入原定义 Excel，和模板保存是两个独立操作。

输出列表保留已确定的图片名和 TXT 数据；直接输出的文件名设定仍按规则处理，所以含 `{random9}` 的规则每次会产生新随机名。需要固定名称时，在「テンプレート設定」的文件名值中填写固定名称。

业务 TAR 内容不增加模板元数据。本功能目前不提供从旧 TAR 自动还原模板。

## 表格批量编辑

FORM 编辑区和 TAR 出力列表均支持单元格矩形选区。蓝色边框表示选中范围。

| 操作 | 方法 |
|---|---|
| 选择一片单元格 | 鼠标拖动，或先点起点再 Shift+点击终点；Shift+方向键扩展范围 |
| 复制 / 剪切 / 粘贴 | Ctrl+C / Ctrl+X / Ctrl+V（macOS 也支持 Command）或右键菜单 |
| 清空内容 | Delete / Backspace；保留行，不删除账票；只读列不会清空 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y；保存最近50次单元格编辑 |
| 单格编辑 | 双击、F2，或选中后直接输入；Enter向下、Tab向右，Shift反向；Esc取消 |
| 全选 | Ctrl+A |

从 Excel 复制多行多列后，单击目标左上角单元格再粘贴。若先选中一片区域，可用单个值填满区域，或按剪贴板矩形重复填充（选区大小必须为剪贴板大小的整数倍）。使用当前可见列顺序，不会写入隐藏列。

遇到只读列、越界、无效出力值（只允许0/1）、空图片基础名、重复图片名等错误，整次粘贴不生效，不截断、不跳列。清空 OCR 同时清空属性和坐标，撤销会一起恢复。清空「出力」设为0；清空图片基础名会报错。删除整行仍使用出力列表的「選択行を削除」。

支持 Excel 的制表符分列、换行分行，以及引号包裹的单元格内换行。不会自动增加账票或定义行；超过现有行数需要先准备相应账票。选区为连续矩形，不支持 Ctrl+点击的不连续单元格选择，也不计算公式。

切换 FORM、重新读取、改变显示列、增加/删除图片或执行其他结构操作会清空当前表的撤销记录。批量编辑后仍需通过默认值保存或模板保存持久化。
